# 編輯排版國手培訓庫（WorldSkills / 國際展能節 · 職類 15）

## 檔案
- `index.html`：培訓網頁，直接用瀏覽器開啟即可，不需要伺服器。
- `glossary.csv`：術語庫的 303 筆中英對照（樂詞網＋勞動部）（Excel 可直接開啟），方便列印或匯入其他工具。

## 頁面
1. **glossary 術語庫**：國教院樂詞網「藝術學名詞」「設計學名詞」中與編輯排版相關的術語，加上勞動部勞動力發展署雙語詞彙中的競賽、技能檢定、印前用語，分八類，有「遮住中文練習」模式。
2. **archive 歷屆考題**：已內建 11 份考題（全國身障賽 2014–2026 共 7 屆、國際展能節第 9／10 屆、全國技能競賽平面設計技術 2 份），內容取自 F:\技能競賽 的原始試題與評分表；團隊可再逐筆登錄新考題。
3. **forecast 趨勢預測**：依考題自動統計（預設只看全國身障賽，可切換範圍），分成「近期新出現／比例上升／持續常考／近期變少」四組。
4. **resources 資源庫**、**discussion 討論區**。

## 資料存放（本機模式）
直接開啟 `index.html` 時，新增的考題、資源、留言存在**這台電腦的這個瀏覽器**（localStorage）。
- 換電腦、換瀏覽器或清除瀏覽紀錄後資料就看不到 → 定期按「匯出資料 (JSON)」備份。
- 和教練、選手交換：一方匯出 JSON，另一方按「匯入並合併」。

若發布成 Claude 線上頁面，同一份網頁會自動改用共用資料庫，團隊成員可以即時共同編輯與留言。
